# FATT — FromAudioToText

Консольная утилита на Python для транскрибации аудио и видео с таймкодами и
локальным распознаванием спикеров. FATT нормализует входной файл через FFmpeg,
распознаёт речь моделью OpenAI Whisper, группирует акустические признаки
голосов локально и сохраняет результат в `.txt` или `.md`.

Пример строки результата:

```text
[00:01:23] Спикер 1: Приветствую всех на созвоне.
[00:01:28] Спикер 2: Добрый день! Давайте начнем.
```

## Возможности

- аудио: `.mp3`, `.wav`, `.m4a`, `.flac`, `.aac`, `.ogg`, `.opus`, `.wma` и другие;
- видео: `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`, `.mpeg`, `.m4v`, `.wmv` и другие;
- автоматическое извлечение и приведение звука к WAV 16 кГц, mono;
- Whisper-модели `tiny`, `base`, `small`, `medium`, `large-v3`;
- полностью локальная диаризация без Hugging Face Token;
- ускорение PyTorch через Apple Metal (`MPS`) на Mac с Apple Silicon;
- индикатор прогресса по трём этапам обработки.

## Структура проекта

Корневой `fatt.py` — только тонкая точка входа. Основная логика разделена по
модулям в `fatt_core/`:

```text
fatt.py                    точка входа
fatt_core/
├── cli.py                 аргументы и координация обработки
├── device.py              выбор MPS/CPU
├── media.py               валидация и FFmpeg
├── diarization.py         локальная диаризация
├── transcription.py       Whisper и объединение таймлайнов
├── output.py              форматирование и запись результата
├── pipeline.py            обработка одного файла
├── progress.py            индикатор прогресса
├── report.py              итоговый отчёт
├── models.py              модели данных сегментов и отчёта
└── errors.py              доменное исключение FATT
tests/test_architecture.py архитектурные проверки проекта
```

Все классы и функции производственного кода имеют русскоязычный docstring. Это
правило проверяется автоматически:

```bash
python -m unittest discover -s tests -v
```

## Установка на Mac с M4

### Шаг 1. Установите FFmpeg

FFmpeg нужен для чтения видео и преобразования аудио:

```bash
brew install ffmpeg
```

Проверьте установку:

```bash
ffmpeg -version
```

### Шаг 2. Создайте виртуальное окружение

Рекомендуется Python 3.10 или новее:

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
```

### Шаг 3. Установите PyTorch с поддержкой MPS

Для актуальных версий PyTorch на macOS обычно достаточно стандартной установки:

```bash
pip install torch torchvision torchaudio
```

Если нужна предварительная версия PyTorch, используйте команду, рекомендованную
на странице установки PyTorch для вашей версии macOS/Python:

```bash
pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/cpu
```

Проверка MPS:

```bash
python -c "import torch; print(torch.backends.mps.is_available())"
```

Ожидаемый результат на совместимом Mac — `True`. Если MPS недоступен, FATT
автоматически использует CPU. MPS задействует GPU Apple через Metal; отдельного
публичного переключателя Neural Engine в PyTorch-коде FATT нет.

### Шаг 4. Установите зависимости FATT

Из корня проекта можно установить все Python-зависимости одной командой:

```bash
pip install -r requirements.txt
```

> FATT использует пакет `ffmpeg-python` как Python-обвязку и установленный в
> системе бинарник `ffmpeg`. Нужны оба компонента.

> Интерактивный мастер использует `prompt-toolkit`: стрелки влево/вправо,
> редактирование строки и вставка путей с пробелами работают как в обычном
> терминальном редакторе.

Путь можно вставлять вместе с внешними кавычками, например:

```text
'/Users/aleksandr/Desktop/#01 - Карты реальности - основы'
```

Внешние кавычки будут убраны автоматически, а `#`, пробелы и кириллица останутся
частью пути.

Для некоторых окружений установка `openai-whisper` также потребует `setuptools`:

```bash
pip install -U setuptools wheel
```

## Локальная диаризация без токенов

FATT не обращается к Hugging Face и не требует `HF_TOKEN`. Диаризация выполняется
локально по акустическим признакам 1,5-секундных фрагментов и их кластеризации.
Whisper также работает локально после однократной загрузки выбранной модели.

Такой режим приватнее и проще в установке, но уступает pyannote на перекрывающейся
речи, шумных записях и очень коротких репликах. Если число голосов известно,
передайте его явно — это улучшает результат:

```bash
python fatt.py -i meeting.m4a --speakers 2 -o meeting.md
```

## Запуск

### Интерактивный мастер

При запуске без аргументов FATT открывает мастер:

```bash
python fatt.py
```

Мастер последовательно попросит:

1. путь к аудио-/видеофайлу или папке;
2. путь к папке для сохранения текстовых результатов.

Если указана папка, FATT рекурсивно найдёт подходящие файлы на любой глубине.
Для каждого файла будет создан отдельный `.txt` с тем же именем, а относительная
структура каталогов будет сохранена только в папке результатов. Пути обрабатываются
через `pathlib.Path`, поэтому работают с разделителями Windows, macOS и Linux.

Индикатор каждого файла выводится последовательно: следующий появляется только
после завершения предыдущего.

После обработки выводится отчёт с результатом, временем, количеством слов,
путём к тексту и причиной ошибки, если файл обработать не удалось.

### Запуск параметрами

Базовый пример:

```bash
python fatt.py -i meeting_video.mp4 -m medium -o protocol.txt
```

Если количество спикеров известно заранее:

```bash
python fatt.py -i meeting.m4a --speakers 2 -o meeting.md
```

Для русской записи можно явно указать язык — это сокращает время автоопределения
и обычно повышает точность:

```bash
python fatt.py -i meeting.m4a --language ru -o meeting.md
```

Обработка папки с сохранением структуры:

```bash
python fatt.py -i recordings/ -o transcripts/
```

Например, файл `recordings/team/april/call.mp4` будет сохранён как
`transcripts/team/april/call.txt`.

Параметры командной строки:

```text
-i, --input      файл или папка; если не указан, запускается интерактивный мастер
-o, --output     файл результата или папка для пакетной обработки
-m, --model      tiny, base, small, medium или large-v3; по умолчанию small
--speakers       количество спикеров, если известно
--language       язык речи, например ru или en
```

В ходе работы отображаются этапы:

```text
[1/3] Извлечение аудио
[2/3] Диаризация
[3/3] Транскрибация Whisper
```

```bash

```

## Обработка ошибок

FATT завершает работу с понятным сообщением, если:

- входной файл отсутствует или имеет неподдерживаемое расширение;
- не найден FFmpeg или он не смог прочитать файл;
- не установлен PyTorch, Whisper, numpy, ffmpeg-python или tqdm;
- в аудио не обнаружена речь для локальной диаризации;
- выходной путь не имеет расширения `.txt`/`.md` или его папка отсутствует.

## Производительность и память

`small` — разумный баланс качества и скорости для M4. `medium` и `large-v3`
обычно дают лучшее качество, но требуют больше памяти и времени. Модели Whisper
скачиваются при первом запуске и кэшируются локально. При пакетной обработке
модель Whisper загружается один раз и повторно используется для всех файлов.
Диаризация выполняется до транскрибации, после чего таймлайны Whisper и локальной
кластеризации объединяются по времени. Для максимальной точности используйте
`large-v3`, для более быстрой обработки — `small` и явный `--language ru`.
